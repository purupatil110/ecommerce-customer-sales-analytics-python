# E-Commerce Customer & Sales Analytics using Python

## Project Overview

This project analyzes e-commerce sales and customer purchasing behavior using Python.

The project includes data cleaning, exploratory data analysis (EDA), sales analysis, customer analysis, RFM analysis, and customer segmentation.

The dataset is a synthetic dataset created for learning and analysis practice.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset

The dataset contains:

- 150 e-commerce orders
- 20 customers
- Multiple products
- Multiple categories
- 5 cities
- Order date
- Quantity
- Unit price
- Sales amount

## Analysis Performed

### Sales Analysis

- Total sales
- Total orders
- Average order value
- Sales by category
- Top products
- Sales by city
- Monthly sales trend

### Customer Analysis

- Top customers by sales
- New vs Repeat customers
- Customer purchasing behavior

### RFM Analysis

RFM analysis was performed using:

- Recency
- Frequency
- Monetary Value

Customers were segmented into:

- Champions
- Loyal Customers
- Recent Customers
- At Risk
- Potential Customers

## Key Business Insights
